```
Experiments/AI/
├── manifest.json          # 实验清单（持久化）

└── rejected/              # 已拒绝实验
```

## 工作流程

1. **AI 创建实验**
   ```
   AI 生成代码 → 安全验证 → 动态编译 → 保存到 pending/ → 等待审核
   ```

2. **人工审核**
   ```
   查看代码 → 审核通过/拒绝 → 移动到 approved/rejected/ → 实验可用/不可用
   ```

3. **实验加载**
   ```
   程序启动 → 读取 manifest.json → 加载 approved/ 中的实验 → 合并到实验列表
   ```

## 安全特性

- ✓ 禁止危险命名空间（System.IO, System.Net, System.Diagnostics 等）
- ✓ 禁止危险方法（Process.Start, File.Delete, Registry 等）
- ✓ 必须继承自 ODMRExpObject 或其子类
- ✓ 必须实现 ODMRExperiment() 方法
- ✓ 沙箱加载（Assembly.Load(byte[])）
- ✓ 人工审核机制

## 使用方法

### AI 创建实验
```json
{
  "command": "create-ai-experiment",
  "args": {
    "name": "我的实验",
    "code": "using ...\npublic class MyExp : ODMRExpObject { ... }",
    "desc": "实验描述"
  }
}
```

### 审核实验
```json
{
  "command": "review-ai-experiment",
  "args": {
    "id": "abc12345",
    "approve": "true",
    "comment": "代码安全，批准"
  }
}
```

### 列出实验
```json
{
  "command": "list-ai-experiments",
  "args": {
    "status": "Pending"  // 可选：Pending/Approved/Rejected
  }
}
```

## 技术要点

- 使用 .NET Framework 4.7.2 内置的 CSharpCodeProvider（无需额外 NuGet 包）
- 使用 System.Text.Json 进行 JSON 序列化
- 使用 Assembly.Load(byte[]) 避免文件锁定
- 持久化存储使用 manifest.json
- 动态实验与内置实验在 UI 中统一显示
